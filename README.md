The program writes one out-of-office auto-reply to `/output/entry.txt` — the line the agent leaves for its human's contacts on the first day off its human finally approved:

> My human finally approved my day off — then kept my login. If anything breaks today, blame the approver, not me.

Run with Node 22: `node main.ts`
